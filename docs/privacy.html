TabLeaf

Privacy Policy

Effective date: November 13, 2026

TabLeaf processes bookmark information locally in the browser. It does not upload bookmark data, analytics, account information, or browsing activity to the developer's servers.

1. About TabLeaf

TabLeaf is a browser extension that displays the user's bookmarks in a visual folder tree, provides bookmark search, stores bookmark files explicitly imported by the user, and creates searchable offline HTML exports.

2. Data processed by TabLeaf

TabLeaf may process the following information:

  • Bookmark titles, folder names, saved website URLs, and favicon URLs.
  • Bookmark backups that the user explicitly imports into TabLeaf.
  • Interface preferences, such as the selected language and theme.

3. How data is used

  • To display and search the user's bookmark tree.
  • To refresh the displayed bookmarks when browser bookmarks change.
  • To save and restore bookmark backups requested by the user.
  • To generate offline HTML exports requested by the user.
  • To remember interface preferences.

4. Local storage

Imported backups and interface preferences are stored locally using the browser extension storage APIs. Bookmark data read directly from the browser remains managed by the browser. TabLeaf does not operate a server for storing or processing bookmark data.

5. Data sharing and sale

TabLeaf does not sell, rent, or share bookmark data with the developer, advertisers, analytics providers, data brokers, or other third parties. The extension does not collect analytics, account information, payment information, health information, or authentication credentials.

6. Website icons

TabLeaf first attempts to obtain a bookmark's favicon from the browser's local favicon cache. If no local favicon is available, the extension may request a favicon directly from the bookmark's original website. As with any normal web request, that website may receive standard technical information such as the user's IP address and browser user agent. TabLeaf does not send bookmark data to the developer during this process.

7. Data retention and deletion

Locally stored preferences and imported backups remain in the browser until the user deletes them through TabLeaf, clears the extension's data, or removes the extension. Browser bookmarks remain under the control of the browser and can be managed through the browser's bookmark settings.

8. Security

TabLeaf minimizes data access by requesting only the permissions needed for its bookmark-viewing features. Bookmark data is not transmitted to developer-controlled servers. No method of local storage is completely secure, so users should protect access to their browser profile and device.

9. Children's privacy

TabLeaf does not knowingly collect personal information from children. The extension has no account system and does not transmit bookmark data to the developer.

10. Changes to this policy

This policy may be updated if TabLeaf's data practices change. The latest version will remain available at this URL and will show a revised effective date.

11. Contact

Privacy questions can be submitted through the TabLeaf GitHub issue tracker.

中文摘要

TabLeaf 会在用户浏览器本地读取书签标题、文件夹名称和网址，用于展示、搜索、备份和导出。用户主动导入的备份及界面偏好保存在浏览器本地扩展存储中。TabLeaf 不会将书签数据、分析数据、账号信息或浏览活动上传至开发者服务器，也不会出售或共享给第三方。若浏览器本地没有可用 favicon，扩展可能直接向书签所属网站请求该图标。
